type: feedback
---

## 为什么

OpenCode v2.0.20 在本次环境多次出现 `models` 正常退出却无条目。用户指出 GLM 可用；其中一次独立模式清单返回了 GLM 与 MiniMax 的真实 provider/model 标识，配置源也确认 GLM-5.3[1M]。隔离的 GLM 文本冒烟实际成功，而后续清单仍为空。空清单与不可用不能画等号；现有证据不足以归因于缓存、配置合并或服务故障。

## 怎么用

先查当前 CLI 文档与帮助，核实用户指定的模型在现有清单或脱敏配置元数据中的完整标识；不猜 provider/model，不读出凭据。清单无输出时，不把同类查询循环三次当排查。已有已核实标识和调用授权时，在新空隔离目录用无工具代理、文件标准输入做一次无项目材料的文本冒烟，以退出码和实际回答共同判断连通性；未经授权不安装、改配置或切换厂商。冒烟失败才按已授权备选处理，失败证据保留，不能把进程退出 0 当作评审完成。
