# specs — 规约：产出该长什么样

> 与开工手册同属「我立的规矩」：**手册管怎么干，规约管产出该长什么样。**
> 多品牌 / 多产品线时，这里一线一份，与作品区一一对应。

## 子目录

| 目录 | 装什么 |
|---|---|
| [`style/`](style/) | **风格档案**——正例、负例、用词表、定标样本 |

**风格不住在真相源里，住在这里。** `vault/` 管「事实是什么」，规约管「产出该长什么样」——
真相源解决不了「应该是什么」。详见 `style/README.md`。

> **形容词自述不可靠，可靠的是你亲手改掉的每一处。风格不是宣言，是改稿史的压缩。**

## 命名：三种命名法

名字里带什么，取决于你日后**怎么找它**——有的靠序号找，有的靠时间找，有的根本不用找、它自己会来。

| 命名法 | 用于 | 样子 | 为什么 |
|---|---|---|---|
| **流水编号** | 档案（调研 · 计划 · 评审） | `001_kebab-case.md` | 要供人引用，**编号一变引用就断**，所以永不重排 |
| **创建日期** | 过程材料 | `2026-07-16_界面审计.md` | 你只关心它什么时候产生的 |
| **最后更新日期** | 记忆 | `20260728-禁用词.md` | 新的覆盖旧的，更新即改名并同步索引 |

> 记忆和档案的差别只有一条：**记忆是下次自动生效，档案是你去查才生效。**
> 命名方式不同，正因为读取方式不同。

规约类文件（被路径引用的那些）**不编号、不带日期**——稳定性是命根，版本走提交链。

### 三个忽略区的目录名

`_build/` `_tmp/` `_archive/` 不入库，但**目录名有硬格式**——它们靠时间排序，格式一乱就再也理不清：

| 目录 | 只许 | 为什么 |
|---|---|---|
| `_build/` | `YYYYMMDD-HHMMSS/` | 一次构建一个；按天分会撞车（一天出多版就互相覆盖） |
| `_tmp/` `_archive/` | `YYYYMMDD-slug/` | 最后更新日期制 |

三区共同规则：**日期一律打头**（方能一路排序、一眼看出时间）；**均禁裸文件与目录混住**（找起来累，管起来更累）。

## 格式

### 提交信息

前缀 `feat` / `fix` / `docs` / `chore`，后接一句话说清改了什么。

**每次改动附五行标注**（照抄）：

```
Change-By:      human | ai | ai+human
Agent:          用的哪个工具
Model:          哪个模型
Suggested-By:   建议来自谁
Co-authored-by: 姓名 <邮箱>
```

**作者亲手改的那些提交，就是日后喂给 AI 学你风格的唯一真相源**——标注是为了日后分得出哪些提交是人亲手改的。

### 产出格式

作品单位的实体语义见 `../.42cog/cog.md`；合格线与实效闭环见 `../.42cog/intent.md`。

- 一次投放目录名：`content/YYYYMMDD-slug/`；slug 使用小写字母、数字和单连字符，日期表示该投放的创建日，排期改变不改名。
- 每个实际投放目录对应实体表中的一行，包含五个非空字段；路径写到该目录，如 `../content/YYYYMMDD-slug/`。
- 必备非空文件：`README.md`（主题、目标受众、渠道、状态）、`core.md`（核心稿）、`sources.md`（来源与事实／推断边界）、`review.md`（规则检查、关联度、人审状态）。
- 按需适配文件：`blog.md`、`wechat.md`、`xiaohongshu.md`、`bilibili.md`；未选择的渠道不建空稿。
- 发布后记录：`metrics.md`，含实际链接、观察窗口、原始指标出处、反馈及解释；尚未发布时不代造结果。
- 核心稿元数据至少包含标题、日期、摘要、标签、状态；默认状态为 `draft`。`reviewed` 或 `published` 必须有对应人审或实际发布记录。
- 人审通过、上传草稿与公开发布是三个不同状态；文章源文件的 `draft: false` 不代表得到发布授权。
- 版本使用 Git 历史，不使用 `-final`、`v2` 或复制整个投放目录存版本。
- `hi.md` 是本人自建的自由手稿，不是必备文件，AI 不代建、不修改；来源凭据与个人数据不进入可提交稿。
- 规则检测：`python3 -I scripts/check-system.py` 仅检查结构和登记；内容真假、风格、人审与发布授权另行验收。
